What each source actually covers

No single Canadian source is complete. Coverage begins at different dates and each has a different idea of what counts as a record.

SourceHoldsFromCatch
CanLII Court decisions Varies by court A case appears only once a judge has written something. A claim filed last week is invisible.
CBA National Class Action Database Filed proceedings and documents 1 January 2007 Voluntary. Lawyers submit to it, so it is not a complete list of every class action in Canada.
Registre des actions collectives Filed proceedings in Quebec 1 January 2009 Official and thorough, but Quebec only.

United States

US federal dockets are searchable live from this page, because CourtListener publishes an open API that a browser may call. No Canadian registry offers that, which is why the sections above link out instead of searching here.

This is not legal advice. Living in a province where a case was started does not by itself make you a class member. Read the decision, or contact class counsel named on it.

Canadian decisions: CanLII, the Canadian Legal Information Institute. Canadian filings: CBA National Class Action Database and the Registre des actions collectives. US dockets: CourtListener RECAP, by the Free Law Project.
